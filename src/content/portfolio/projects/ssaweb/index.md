서버 분산 처리 수요가 커지는 흐름에 맞춰, 로봇이 보낸 영상을 서버에서 처리하고 그 결과를 웹으로 내보내는 시스템을 1인으로 만들었습니다. Full Stack 으로 웹 인터페이스와 서버 통신 시스템, 영상처리를 모두 담당했습니다.

- 로봇(Raspberry Pi)이 센서 값과 영상을 서버로 송신
- 서버가 영상을 로컬의 YOLO 서버로 넘기고 결과를 받아 웹 서버로 전달
- 모든 중계를 비동기로 처리해 통신 성능 확보
- 프런트에서 센서 데이터를 실시간 차트로, 검출 결과와 영상을 함께 표시

#### 회고

- 실시간 스트리밍 속도 개선을 위해 RTP 도입이 필요합니다.
- 서버에 로드 밸런싱을 적용하면 분산 처리 기능을 확장할 수 있을 것으로 보입니다.
- Log 저장 기능은 구현했지만 쓰임이 애매해 데모에서 활용하지 못했습니다. DB 를 활용하는 방향으로 보완이 필요합니다.
- 라즈베리파이 카메라 고장으로 실시간 촬영 대신 별도 동영상으로 대체해 시연했습니다.

`Vue.js` `Node.js` `YOLOv9` `MySQL` `Nginx`
