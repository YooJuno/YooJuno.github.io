#### 철도 점검 로봇의 공간 인지와 주행

3D LiDAR 주행 기록으로 지도를 만들고 위치 추정을 검증했습니다. GSeg3D로 경사 구간의 지면을 분리하고, 기록 데이터를 재생해 Nav2 Ground Consistency Layer가 지면 높이를 기준으로 장애물을 반영하는지 확인했습니다.

전방 카메라의 AprilTag로 도킹 목표 자세를 구해 진입과 정렬을 시험했습니다. 열차 정차 거리 측정과 관제 연동을 맡았으며, 현재는 LiDAR 점군의 검출 대상을 라벨링하고 검출 결과를 확인하는 작업도 진행하고 있습니다.

[철도 점검 로봇 자율주행](#proj-rail-inspection)

#### Go2 실내 매핑과 자율주행

Elevator-LIO의 공개 구현을 Go2 실기에 적용하고, 건물 안에서 수집한 LiDAR와 IMU 데이터로 지도를 만들었습니다. 생성한 지도와 위치 추정 결과를 실내 주행에 활용할 수 있도록 DDDMR과 연동하는 작업을 진행하고 있습니다.

#### 사족보행 로봇 현장 시험

Go2X의 3D 지도와 고도 지도를 시험했습니다. Go2에서는 IMU 자세를 반영해 LiDAR 점군을 실시간 보정하고 현장에서 불필요한 바닥 점이 줄어드는 것을 확인했습니다.

#### ROS 2 드라이버 표준화

로봇·센서 SDK를 공통 패키지로 정리하고, ROS 버전별 드라이버와 설치·실행 문서를 표준화했습니다.

#### 현장 도구

PGM·YAML 지도와 주행 마스크를 편집하는 도구를 만들었습니다. RGB-D 카메라 Studio의 미리보기·녹화·점군 표시를 개선했습니다.

[지도 편집기](/utilities/map-editor/)

#### 현장 통합·배포

이동 플랫폼·로봇팔 전시 데모를 통합하고 전원 강하를 분석해 전원 구성을 보완했습니다. 센서 사용·검수 문서를 작성하고 GitHub Actions로 빌드·배포를 자동화했습니다.
