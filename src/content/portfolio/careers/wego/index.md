#### 자율주행 연구·개발

사족보행 로봇의 3D SLAM·Navigation 연구와 SI 프로젝트의 자율주행 로봇 개발.

Go2X의 험지 인식을 위해 3D 지도와 고도 지도 생성을 시험했습니다. Go2에서는 IMU의 롤·피치를 반영해 LiDAR 점군을 실시간으로 수평 정렬했습니다.

철도 점검 프로젝트에서 LiDAR·IMU 주행 기록을 정합해 공통 지도를 만들고, Nav2 주행과 관제를 연동해 실기 웨이포인트 주행을 시험했습니다. LiDAR 기반 열차 정차 거리 측정과 AprilTag 도킹도 개발했습니다.

[철도 점검용 사족보행 로봇 자율주행](#proj-rail-inspection)

#### 시스템 레이어 설계

제조사 SDK·드라이버를 연동하고 로봇·센서와 상위 소프트웨어 사이의 시스템 레이어 설계.

#### 재사용 가능한 패키지 체계

로봇·센서 연동 기능을 사내 패키지로 구성했습니다. 제조사 드라이버를 ROS 버전별로 정리하고, 패키지의 설치·실행 절차와 인터페이스 문서를 표준화했습니다.

#### 현장 도구 개발

지도 편집기를 개발해 PGM·YAML 지도와 주행용 마스크를 내보내는 기능을 구현하고 검증 결과를 사내에 공유했습니다. RGB-D 카메라 Studio의 미리보기, 녹화, 3D 점군 표시를 개선했습니다.

#### 현장 시스템 통합

이동 플랫폼과 로봇팔을 연동한 전시 데모에서 전원 강하를 분석해 전원 구성을 보완하고 통합 동작을 검증했습니다.

#### 배포·유지보수 자동화

현장 시스템의 배포 절차를 자동화해 유지보수 환경을 구성했습니다. 센서 사용자 매뉴얼과 검수 문서를 작성하고 GitHub Actions 기반 자동화 워크플로를 구성했습니다.
