#### 자율주행·지형 인식

철도 점검용 B2의 지도·주행·관제를 연동하고, 열차 정차 거리 측정과 AprilTag 도킹을 개발했습니다. Go2X의 3D·고도 지도와 Go2의 IMU 기반 점군 수평화를 시험했습니다.

[철도 점검 로봇 자율주행](#proj-rail-inspection)

#### ROS 2 드라이버 표준화

로봇·센서 SDK를 공통 패키지로 정리하고, ROS 버전별 드라이버와 설치·실행 문서를 표준화했습니다.

#### 현장 도구

PGM·YAML 지도와 주행 마스크를 편집하는 도구를 만들었습니다. RGB-D 카메라 Studio의 미리보기·녹화·점군 표시를 개선했습니다.

[지도 편집기](/utilities/map-editor/)

#### 현장 통합·배포

이동 플랫폼·로봇팔 전시 데모를 통합하고 전원 강하를 분석해 전원 구성을 보완했습니다. 센서 사용·검수 문서를 작성하고 GitHub Actions로 빌드·배포를 자동화했습니다.
