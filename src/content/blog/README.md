# 블로그 글 관리

방문자 화면은 `/blog/`, 관리자 화면은 `/admin/`입니다.
관리자 로그인 연결과 발행 절차는 [CMS 안내](../../../docs/blog-cms.md)를 참고하세요.

## 저장 구조

```text
src/content/blog/
└─ article-slug/
   ├─ index.md
   └─ image.png
```

글과 이미지는 같은 폴더에 둡니다. 본문에서는 `![설명](./image.png)`로 참조합니다.
관리자 편집기의 이미지 버튼으로 업로드해도 같은 구조로 저장됩니다.
공용 미디어 라이브러리에서 올린 파일은 `public/content/images/blog/`에 저장됩니다.

## 메타데이터

```yaml
---
title: 글 제목
slug: article-slug
date: '2026-10-26'
category: 개발
tags:
  - ROS2
summary: 주제와 적용 범위를 한 문장으로.
---
```

- `slug`는 폴더 이름과 같아야 합니다. 기존 글의 대소문자·주소는 유지합니다.
- `date`는 최초 발행일입니다. 단순 수정 때문에 바꾸지 않습니다.
- `summary`는 목록에서 주제를 구분할 수 있는 짧은 한 문장으로 씁니다. 배경·목차·주의사항은 본문에 둡니다. YAML의 여러 줄 문자열도 지원합니다.
- 제목은 “평가 지표”, “설정 항목”처럼 내용을 바로 알 수 있게 씁니다. 반복 안내·수사적 질문은 줄이되 가정·단위·제약·출처는 남깁니다.
- 그림은 밝은 배경과 무채색 선·문자를 기본으로 합니다. 색만으로 항목을 구분하지 않고 라벨·선 모양을 함께 사용합니다.
- 코드·표·수식이 있는 기존 자료는 Markdown 모드를 우선 사용합니다.
- 관리자 화면은 원문을 자동 교정하거나 이미지 파일을 일괄 재작성하지 않습니다.
- 이 저장소는 공개되어 있으므로 CMS 초안 브랜치도 GitHub에서 읽을 수 있습니다. 비밀정보를 작성하지 않습니다.

수정 전 `npm run blog:backup`, 수정 후 `npm run blog:check`로 백업과 경로 검사를 실행할 수 있습니다.
